# CS231 Digital Logic Project

Course project covering the design, analysis, and simulation of combinational and sequential digital circuits.

## Project contents

- A combinational circuit that identifies even and prime numbers from 1 to 10.
- A sequential circuit implemented with D flip-flops.
- A sequential-circuit design implemented with JK flip-flops, including analysis of unused states.
